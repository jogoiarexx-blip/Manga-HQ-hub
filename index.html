Como ler os arquivos do Drive no app?
  1. Deixe as pastas como públicas em Qualquer pessoa com o link.
  2. Para sincronizar novidades automaticamente, crie uma API Key no Google Cloud com a Google Drive API ativada.
  3. Restrinja a chave ao endereço do seu GitHub Pages e à Google Drive API.
  4. Cole a chave acima, toque em Testar conexão e depois em Salvar e sincronizar.
  5. Na biblioteca, toque em Ler agora. Pastas com manifest.json + páginas WebP abrem página a página; PDF, CBR e CBZ continuam compatíveis.

Arquivos privados exigem autenticação OAuth; uma API Key sozinha serve para conteúdo público.
